# ✈️ French Travel - Agencia de Viajes

Página web profesional para **French Travel**, una agencia de viajes especializada en todo tipo de experiencias alrededor del mundo.

## 🌐 Ver en Vivo

👉 [https://diego302000-ui.github.io/french-travel-web/](https://diego302000-ui.github.io/french-travel-web/)

## 🎨 Características

- ✅ Diseño responsive (móvil, tablet y desktop)
- ✅ Paleta de colores dorados y naturales
- ✅ Hero con slider de imágenes automático
- ✅ Buscador de viajes
- ✅ Sección de destinos populares
- ✅ Paquetes con filtros interactivos
- ✅ Sección de videos (próximamente)
- ✅ Testimonios con slider
- ✅ Formulario de contacto/cotización
- ✅ Newsletter
- ✅ Botón flotante de WhatsApp
- ✅ Animaciones al scroll
- ✅ Contadores animados

## 📁 Estructura

```
├── index.html    → Página principal
├── styles.css    → Estilos y responsive
├── script.js     → Interactividad
├── logo.png      → Logo de French Travel
└── logo.svg      → Logo en formato vectorial
```

## 🚀 Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, Animaciones)
- JavaScript (Vanilla)
- Google Fonts (Playfair Display + Lato)
- Font Awesome 6

## 📱 Responsive

La página está optimizada para:
- 📱 Móviles (320px - 480px)
- 📱 Tablets (481px - 1024px)
- 💻 Desktop (1025px+)
